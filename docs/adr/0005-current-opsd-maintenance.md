# 维护当前 OPSD，历史实验使用固定版本

2026-10-16：用户确认当前只维护从原始指令模型开始的 OPSD、当前数据来源的完整准备链、共享 Harness、PyTRIO 训练和本地 vLLM 评测。SFT 制作、训练、验收、SFT 起点，以及旧协议专属实验退出维护；这取代 ADR-0003 中保留 SFT 可选起点的决定。冻结教师、原始 token 监督、任务家族隔离、费用与恢复一致性仍是算法保证。

旧实验通过 `opsd-536-before-refactor-20261016`（`ea10824`）或其对应历史提交运行。该基线包含 536 次更新期间尚未提交的实现。数据、权重、运行记录和依赖锁另行保留。最新代码不承诺原地恢复旧运行目录，已导出的模型仍可用于新评测。

每个新实验使用一个配置入口，引用可复用的协议、环境和服务配置。配置统一解析并记录最终值，训练与评测共享研究条件。实验参数属于配置；代码检查实际运行是否符合冻结条件，不把某一次实验的轮数、预算或种子个数写成通用约束。

任务清单冻结任务家族、训练子集及来源。训练轮数、训练／评测种子和访问顺序由本次实验配置决定，并在运行记录中冻结；更改新实验的轮数不要求重新执行数据转换。原数据产物中的历史访问计划仍受来源完整性校验，但不限制新实验的执行计划。
