**Blocked by:** 无（可立即开始；沿用已交付的本地推理、任务池和示范导出能力）。

**Status:** ready-for-agent

- [x] 采样前冻结 9 个训练家族，短程序编写、现有代码修改、工作区信息利用各 3 个。保存任务、初始状态、来源、划分与内容身份；两个协议使用相同清单，不引入开发或最终测试家族。
- [x] 核验实际加载的原始模型快照、权重、tokenizer、编码及 token／逐 token logprob 能力。根据实际显存和上下文条件准备服务，保留其他正在使用的服务，不能把旧 SFT 服务当作原始模型。
- [x] 固定模型、任务初始状态、seed、采样、环境及实际服务条件，仅改变协议名称和系统提示。未改变的采样设置沿用已有原始模型方案，并在运行前冻结。
- [x] 两组均使用最多 10 步、8192 个生成 token、300 秒。服务窗口与完整历史上限相同，并容纳系统提示、任务、生成和真实观察。保持上下文只追加，容量不足单独记录。

- [x] 按协议和任务类型报告有效行动的分子／分母、格式错误、虚构观察行为审阅、提交数、评分通过数、预算与上下文耗尽。给出配对逐任务结果；虚构观察判断绑定原回复，不仅按标签出现次数推断。
- [x] 对可用候选逐行动审阅，经已有执行、回放、冻结及训练加载流程核验真实观察、监督掩码、提交和独立评分。分别报告尝试、候选、可加载示范、独立家族、输入与监督 token，以及拒绝原因。
